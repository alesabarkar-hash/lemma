# Правила названий для игровых материалов LEMMA

Инструкция для человека без опыта в программировании. Технические
слова объясняю сразу рядом.

## Обновление на этом этапе: правило названий изменилось

Раньше в этом документе для файлов персонажей использовалось
подчёркивание: `lumi_joy.webp`. **С этого этапа правило другое —
дефис**, по образцу, который задал владелец проекта:

```
assets/characters/lumi/source/lumi-upload-01.png   — исходник
assets/characters/lumi/images/lumi-neutral.webp    — игровая версия
```

Старое правило (подчёркивание) больше не действует для новых
файлов. Уже подключённые к сайту файлы Луми названы по новому,
дефисному правилу — переделывать ничего не нужно.

## Два списка чувств — вопрос решён для Луми

Раньше здесь было два конкурирующих списка названий эмоций —
старый (в коде: happy, excited, thinking…) и новый (joy, calm,
inspiration…). **Для Луми решение принято: используется новый
список**, конкретно те 10 названий, для которых сейчас есть
готовые изображения:

```
neutral, joy, enthusiasm, explanation, calm,
laughter, surprise, support, doubt, inspiration
```

Не хватает: **thinking, success** — материалы для них владелец
пришлёт позже.

Для Эхо, Флипа и Олли этот вопрос пока не решён — у них есть
только эталонные листы-референсы (все 12 эмоций одной картинкой
с подписями), но не отдельные файлы для превращения в игровые
версии. Когда они появятся, эта же дефисная система названий
и то же разделение source/images будет применено к ним.

## Структура папок персонажа (актуальная, на примере Луми)

```
assets/characters/lumi/
├── source/            — исходники, как прислали, без изменений
│   ├── lumi-upload-01.png … lumi-upload-11.png
├── images/             — облегчённые версии для сайта (WebP, прозрачный фон)
│   ├── lumi-neutral.webp, lumi-joy.webp, lumi-enthusiasm.webp,
│   │   lumi-explanation.webp, lumi-calm.webp, lumi-laughter.webp,
│   │   lumi-surprise.webp, lumi-support.webp, lumi-doubt.webp,
│   │   lumi-inspiration.webp
├── review-later/       — спорные изображения, пока не используются
│   └── lumi-upload-04-unclear.png
├── videos/, sounds/, emotions/   — подготовлены, пока пустые
└── lumi_emotion_sheet_reference.png   — эталонный подписанный лист
```

Папка `_unconfirmed_matching`, которая была временным местом на
предыдущем этапе, больше не существует — все файлы из неё
разложены по местам выше.

## Как обрабатывались изображения (что уже сделано, не инструкция на будущее)

Для десяти сопоставленных изображений:
1. фон сделан прозрачным (был белый, теперь можно накладывать на
   любой цвет интерфейса);
2. пустые прозрачные поля по краям обрезаны — сам персонаж,
   уши, лапы, хвост и аксессуары при этом не обрезались, обрезка
   идёт только там, где вообще нет непрозрачных пикселей;
3. все десять картинок приведены к одной и той же высоте (760
   точек) — единый визуальный масштаб между эмоциями;
4. сохранено в формате WebP, вес уменьшился примерно в 23 раза
   (с 1,5–2,2 МБ до 73–104 КБ на файл).

## Как заменить картинку (по-прежнему просто)

1. Открываете `assets/characters/lumi/images/`.
2. Находите файл, например `lumi-joy.webp`.
3. Заменяете новым файлом с точно таким же именем.
4. Код сайта трогать не нужно — он сам подхватит новый файл.

## Если эмоции пока нет

Код сайта устроен так, что отсутствующая эмоция автоматически
подменяется нейтральным изображением Луми — без сломанной
картинки, без пустого места. Так сейчас работает для **thinking**
и **success**. Как только появится файл `lumi-thinking.webp` или
`lumi-success.webp` в папке `images/` — достаточно вписать
название эмоции в список `LUMI_READY_EMOTIONS` внутри `index.html`
(это одна строка, я могу сделать это за минуту, когда файл будет
готов).
