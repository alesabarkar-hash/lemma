# Готовность LEMMA к продаже

Оценка честная, без выдуманных цифр стоимости — денежную оценку
здесь никто не делает, это не моя область и не задача этого
документа.

---

## Продукт
**Статус: рабочий прототип с одним полностью готовым классом,
персонаж Луми впервые подключён внутри урока.**
- Готово: цельная идея, работающий движок уроков, учебник, игра,
  родительский раздел, современный лендинг, Луми присутствует
  и реагирует на ответы ученика в уроке (10 из 12 эмоций).
- Не хватает: наполнения классов 3–9, настоящего LUMA, регистрации,
  двух оставшихся эмоций Луми, аналогичного подключения для
  Эхо/Флипа/Олли.
- Сильнее всего поднимет ценность: наполнение хотя бы ещё
  одного-двух классов учебным контентом — превращает продукт из
  «демо одного класса» в «действующий курс на несколько лет».
- Ближайший безопасный шаг: решить открытые вопросы по названиям
  (KNOWN_ISSUES.md), подключить подтверждённые эмоции персонажа.

## Учебный контент
**Статус: качественно, но узко.**
- Готово: 2 класс — десять тем, полный учебник, все задания,
  все распечатки.
- Не хватает: содержимого для классов 3–9; официальной проверки
  качества контента (грамматика, соответствие возрасту) сторонним
  педагогом.
- Сильнее всего поднимет ценность: заключение независимого
  учителя английского о соответствии содержания школьной
  программе — это то, что покупатель не сможет проверить сам
  быстро, а вы можете сделать заранее.
- Ближайший безопасный шаг: наполнение 3 класса по образцу
  уже готового 2-го.

## Код
**Статус: работает, но пока не подготовлен к передаче другому
разработчику.**
- Готово: единая логика, подписанные разделы внутри файла,
  проверки после каждой правки, история версий.
- Не хватает: разделения на отдельные файлы (сейчас один большой
  файл — см. ROADMAP.md), автоматических тестов, отдельного
  административного режима вместо служебных экранов.
- Сильнее всего поднимет ценность: постепенное разделение кода
  на модули — новому разработчику будет проще войти в проект.
- Ближайший безопасный шаг: этап 1 из плана разделения
  (картинки и видео — уже частично начато).
- **Обновление v1.5:** все три средних риска из аудита исправлены
  и проверены (единая формула прогресса с контрольным сравнением
  до/после, безопасный вывод пользовательского текста, уникальные
  id в иллюстрациях). Визуальная проверка на реальных устройствах
  по-прежнему не проведена — подготовлен чек-лист для владельца.
- **Обновление после полного аудита (v1.4):** проведена реальная
  техническая проверка (не только «код запускается») — найдены и
  зафиксированы 3 средних технических риска (дублирование формулы
  прогресса, отсутствие экранирования пользовательского текста,
  совпадающие id в SVG). Ни один не критичен, все задокументированы
  в `FULL_SITE_AUDIT.md`, ничего не скрыто.

## Документация
**Статус: только что запущена.**
- Готово: девять базовых документов (эта папка), история версий,
  правила названий файлов.
- Не хватает: инструкции по добавлению нового учебного материала

- Сильнее всего поднимет ценность: подробная инструкция «как

- Ближайший безопасный шаг: обновлять уже созданные документы
  после каждого следующего этапа, не откладывать.

## Безопасность
**Статус: рисков немного, потому что мало что подключено.**
- Готово: нет паролей, нет платежей, нет реальных данных детей —
  подключать нечего, значит нечего и взломать.
- Не хватает: самой темы ещё не существует, пока нет сервера
  и регистрации.
- Сильнее всего поднимет ценность: ничего специально делать не
  нужно сейчас — просто не торопиться подключать сервер раньше,
  чем он будет к этому готов.
- Ближайший безопасный шаг: следовать плану (сначала локально,
  потом сервер, потом публикация) — уже так и делается.

## Права на материалы
**Статус: требует внимания, самое слабое место сейчас.**
- Готово: реестр материалов начат (ASSET_REGISTER.md), статусы
  честно расставлены.
- Не хватает: подтверждения прав на базовые изображения
  персонажей (они существовали до начала документирования) и на
  новые присланные материалы (сам паспорт персонажей просит
  проверить лицензии ИИ-сервисов перед коммерческим использованием).
- Сильнее всего поднимет ценность: **это единственный пункт,
  который может реально помешать продаже**, если его не решить —
  подтверждение прав на изображения персонажей и распечатки.
- Ближайший безопасный шаг: связаться с тем, кто заказывал
  генерацию изображений персонажей, и сохранить любые
  подтверждения (переписку, чеки, условия сервиса).

## Зависимость от владельца
**Статус: высокая — типично для раннего проекта.**
- Готово: код читаем, подписан комментариями, история изменений
  ведётся — уже снижает зависимость по сравнению с полностью
  недокументированным кодом.
- Не хватает: происхождение части материалов знает только
  владелец (не зафиксировано нигде); опыт работы с этим
  конкретным сайтом пока есть только у владельца.
- Сильнее всего поднимет ценность: зафиксировать в
  HANDOVER_GUIDE.md всё, что сейчас знает только один человек.
- Ближайший безопасный шаг: продолжать вести документацию по
  ходу разработки, не откладывать на «потом перед продажей».
