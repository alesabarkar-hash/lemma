# Структура проекта

## Коротко

Сайт LEMMA сегодня — **один файл** `index.html` (около 600 КБ)
плюс несколько папок с картинками и файлами для скачивания.
Так сделано намеренно на старте проекта — просто и быстро для
разработки в одиночку. Внутри этого одного файла код уже поделён
подписанными разделами (что-то вроде оглавления прямо в тексте
файла), поэтому ориентироваться в нём можно, хотя физически
файлов пока немного.

## Что находится внутри index.html

Файл поделён на подписанные комментариями разделы. Если открыть
файл в любом текстовом редакторе и поискать (Ctrl+F) заголовок
из списка ниже — сразу попадёте в нужное место:

| Ищите в файле | Что там |
|---|---|
| «ДИЗАЙН-СИСТЕМА ЛЕММЫ» | Цвета, шрифты, отступы — общий стиль |
| «ПУБЛИЧНЫЙ РЕЖИМ» | Стили публичной главной страницы |
| «КОНТЕНТ» | Все тексты уроков, слова, задания — учебное содержимое |
| «НАВИГАЦИЯ» | Переключение между разделами сайта |
| «ГЛАВНАЯ» | Публичная страница-лендинг |
| «УРОК» | Механика прохождения занятия |
| «УЧЕБНИК» | Постраничное чтение книги |
| «ИГРОВОЙ ДВИЖОК ЛЕММЫ» | Лемы, прогресс, сохранения |
| «МИРОВОЙ СЛОЙ ЛЕММЫ» / «NOVA WORLD» | Игровая часть, спутники, карта |
| «AI-НАСТАВНИК LUMA» | Кристалл-помощник (пока оболочка) |
| «БЕЗОПАСНЫЙ ВЫВОД ПОЛЬЗОВАТЕЛЬСКОГО ТЕКСТА» | Функция escHtml() — единое место экранирования имени профиля/спутника |
| «ЛУМИ В УРОКЕ» | Реестр реакций персонажа-спутника Луми — отдельно от кристалла LUMA, это разные вещи |
| «ДЛЯ РОДИТЕЛЕЙ» | Родительский раздел |

## Почему пока один файл, а не много маленьких

Один файл проще открыть, проверить и откатить назад одной
командой — это специально выбранный, осторожный подход на раннем
этапе. План постепенного разделения на отдельные файлы описан
в ROADMAP.md — это будущий этап, не выполненный сейчас.

## Размер

`index.html` — примерно 596K; вся папка
`assets` (без новых присланных материалов) — около 416 КБ.
Новые присланные материалы персонажей добавили дополнительно
около 34 МБ — это временные, ещё не оптимизированные для сайта
файлы, см. ASSET_REGISTER.md.
