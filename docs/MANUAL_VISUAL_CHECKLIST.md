# Список ручной визуальной проверки

Простыми словами: это список того, что нужно проверить глазами —
в настоящем браузере, на настоящем телефоне. Я такую проверку
провести не могу, в моей рабочей среде браузера физически нет.
Всё, что я писал о вёрстке раньше, — это расчёт по числам в коде,
не то же самое, что взгляд живого человека.

**Не считайте пункты ниже пройденными, пока не проверили их сами.**

---

## Как открыть сайт для проверки

1. Скачайте и распакуйте архив `lemma-v1.5.zip`.
2. Найдите файл `index.html`, откройте его в браузере (двойной клик
   или через «Открыть с помощью»).
3. Для проверки на телефоне — тот же файл можно открыть на телефоне
   (например, отправить себе по почте/мессенджеру и открыть) или
   в браузере компьютера включить режим «как на телефоне»:
   в Chrome — три точки → Дополнительные инструменты → Инструменты
   разработчика → значок телефона/планшета в левом верхнем углу
   открывшейся панели.

## 1. Ширины экрана — по одному прогону на каждую

Для каждой ширины: открыть режим «как на телефоне» (см. выше),
в верхней панели вписать нужную ширину в пикселях.

| Ширина | Устройство-ориентир |
|---|---|
| 320 px | самый маленький iPhone |
| 360 px | средний Android |
| 375 px | iPhone стандартный |
| 390 px | iPhone новее |
| 414 px | iPhone Plus/Max |
| 430 px | iPhone Pro Max |
| 768 px | планшет (вертикально) |
| 1024 px | планшет (горизонтально) / маленький ноутбук |
| 1280 px | обычный ноутбук |
| 1440 px | большой монитор |
| 1920 px | полноэкранный монитор |

## 2. Что проверять на каждой ширине

Открывайте по очереди разделы и для каждого смотрите на список ниже.

### Шапка и общее
- [ ] логотип «ЛЕММА» виден полностью, не обрезан;
- [ ] подпись под логотипом не съезжает на 2–3 строки;
- [ ] кнопки в шапке (копилка, «Мир», профиль) не наезжают друг на друга;
- [ ] нет горизонтальной прокрутки всей страницы (если можно
  свайпнуть влево-вправо и увидеть, что страница «шире экрана» —
  это ошибка, сделайте скриншот).

### Нижнее меню (на телефоне)
- [ ] все 5 пунктов меню видны и подписаны;
- [ ] меню не перекрывает текст или кнопки над собой;
- [ ] нажатие на каждый пункт ведёт в правильный раздел.

### LUMA (кристалл-помощник)
- [ ] кристалл виден в правом нижнем углу;
- [ ] не перекрывает нижнее меню;
- [ ] не перекрывает кнопку «Дальше» во время урока;
- [ ] открывается по нажатию, закрывается по крестику;
- [ ] окно помощника не съезжает за край экрана.

### Персонажи (Луми и другие)
- [ ] изображение не растянуто и не сплющено;
- [ ] уши, лапы, хвост не обрезаны рамкой экрана;
- [ ] персонаж не перекрывает текст задания.

### Урок
- [ ] заголовок темы виден;
- [ ] текст читается, не мелкий;
- [ ] варианты ответа — каждый легко нажать пальцем (не слишком мелкие);
- [ ] кнопка «Дальше» видна и доступна, не спрятана за нижним меню;
- [ ] после ответа реакция Луми появляется рядом с заданием, не
  перекрывая вопрос или варианты.

### Учебник
- [ ] страница читается целиком без лишней прокрутки в стороны;
- [ ] кнопки «Назад»/«Вперёд» доступны;
- [ ] иллюстрация на странице не обрезана и не искажена;
- [ ] номер страницы виден.

### Родительский раздел
- [ ] таблица или карточки прогресса не съезжают, читаются целиком;
- [ ] длинные названия тем не обрезают соседние цифры.

### Магазин / игра
- [ ] карточки товаров не налезают друг на друга;
- [ ] цена и кнопка покупки видны на каждой карточке.

### Модальные окна (всплывающие)
- [ ] окно по центру экрана, не обрезано сверху/снизу;
- [ ] есть понятная кнопка закрытия;
- [ ] фон за окном не даёт нажимать на что-то под ним случайно.

### Специально про iPhone
- [ ] нижняя полоска-«домик» iPhone не перекрывает кнопки —
  особенно кнопку «Дальше» в уроке и нижнее меню;
- [ ] при повороте телефона боком ничего не разваливается
  (спокойно, если станет неудобно — это не критично, но
  зафиксируйте).

## 3. Как сделать скриншот при найденной ошибке

- **iPhone:** одновременно нажать боковую кнопку и кнопку
  громкости вверх.
- **Android:** обычно кнопка питания + кнопка громкости вниз
  (может отличаться у разных производителей).
- **Компьютер (Windows):** клавиша PrtScn, или Win+Shift+S для
  выделения области.
- **Компьютер (Mac):** Cmd+Shift+4 для выделения области.

## 4. Как понять, что проблема настоящая, а не показалось

- Проверьте на **двух разных ширинах подряд** — если проблема
  видна только на одной конкретной ширине (например, ровно 375px)
  и пропадает на соседних — это тоже стоит зафиксировать, но
  пометьте «узкий диапазон».
- Проверьте, повторяется ли при обновлении страницы (F5 /
  свайп вниз на телефоне).
- Если что-то выглядит странно, но не мешает нажать нужную кнопку
  и пройти дальше — это «желательно улучшить», не «критично».
- Если что-то **не даёт** дойти до кнопки, прочитать текст целиком
  или ответить на задание — это «важно», сообщайте отдельно.

## 5. Куда записывать находки

Проще всего: скриншот + одна строка текста вида
«370px, экран урока, кнопка Дальше наполовину скрыта нижним меню».
Этого достаточно, чтобы я нашёл место в коде и поправил.
