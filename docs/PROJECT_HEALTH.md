# Здоровье проекта LEMMA

Снимок состояния на момент последней стабильной версии. Обновляется
после каждой контрольной точки — не задним числом, а по фактическому
состоянию файлов на момент обновления.

---

## Текущая версия

**v1.37** — 3 августа 2026 (Mobile Overflow)

## Экраны

**24** зарегистрированных экрана (`SCREENS` в `index.html`).
Пользователю в обычном интерфейсе доступны 23 — `s-diag` открывается
только по `?diag=1`, кнопок на него в интерфейсе нет (см. `DECISIONS.md`,
ADR-007 про соседний по духу `s-learn`).

## Тесты

**197** автоматических браузерных теста (Playwright), все зелёные на
последней стабильной версии. Минимум два полных прогона перед каждой
версией — стабильность подтверждается повторно, не однократно.

Тест-раннер сохраняет полные улики (HTML, скриншот, состояние класса,
ошибки консоли) при любом падении — начиная с A2.

## Известные ограничения

**9 открытых** записей в `KNOWN_ISSUES.md` (десятая — про
горизонтальную прокрутку — закрыта в v1.37, оставлена в файле как
разрешённая, не удалена, чтобы сохранить историю диагностики).

Из открытых — самые значимые для покупателя:
- Практика 3 класса закрыта целиком (недостаточно материала для
  честного порога, решение отложено до наполнения 3 класса);
- Учебник и Распечатки 3 класса пусты (данных ещё нет);
- права на иллюстрации персонажей требуют проверки перед публичным
  запуском (см. `ASSET_REGISTER.md`).

## Архитектурные решения (ADR)

**9 записей** в `DECISIONS.md`, включая обязательные восемь из
`подготовка_к_продаже.txt` и одну по итогам Mobile Overflow.

## Мобильная проверка

Последняя формальная проверка — этап Mobile Overflow, ширины 320 /
375 / 390 / 430 px, четыре экрана раздела «Учиться». Горизонтальная
прокрутка устранена и покрыта регрессом. Полная ручная проверка на
реальных устройствах (не headless-браузере) не проводилась — см.
`Основа_.txt`, раздел 16: «Требует ручной визуальной проверки Алесей».

## Статус готовности к продаже

**Frontend MVP**, не Production Service (см. `подготовка_к_продаже.txt`,
раздел 2, и подтверждено в `Мастер_файл.txt`, раздел 19). Сервера,
базы данных, авторизации, реальных платежей — нет. Синхронизация между
устройствами — вручную, кодом переноса.

Наполнение: 2 класс полностью готов (10 тем, учебник, распечатки,
тренажёры, углублённый английский). 3 класс — частично (2 из 6 тем,
без учебника/распечаток/тренажёров). Классы 4–9 не начаты.
