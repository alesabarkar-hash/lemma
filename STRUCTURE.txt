ЛЕММА — структура проекта

index.html                     весь сайт одним файлом
worksheets/                    18 листов для печати (PDF, 46 страниц)
assets/                        центральное хранилище ресурсов
  README.txt                   как всё устроено
  lumi.webp echo.webp
  flip.webp ollie.webp         базовые изображения спутников
  lineup.webp                  общий ряд персонажей
  characters/lumi/             состояния Луми
  characters/echo/             состояния Эхо
  characters/flip/             состояния Флипа
  characters/ollie/            состояния Олли
  world/                       локации и зоны игрового хаба
  ui/                          фирменные элементы интерфейса
  effects/                     частицы, вспышки, переходы
  items/                       одежда, мебель, награды
  pets/                        маленькие питомцы
  animations/                  покадровые ленты и Lottie
  scenes/                      сюжетные сцены тем
  game/                        прочая графика игры

В каждой папке лежит README.txt с точными именами файлов,
форматом, пропорциями и предельным весом.

КАК ПОДКЛЮЧИТЬ ИЗОБРАЖЕНИЕ
1. Положить файл в нужную папку с именем из её README
2. Открыть index.html, найти «ЕДИНАЯ СИСТЕМА РЕСУРСОВ»
3. Вписать имя файла без расширения в ASSET_MANIFEST
   Например:  world:["zone_workshop","hub_background"]
4. Перезагрузить страницу

Пока файла нет, рисуется временная заглушка с подписью.
Запросов к серверу и битых ссылок не возникает.

ГДЕ ПРОВЕРИТЬ
Кабинет → «Ресурсы проекта»        сколько файлов подключено по папкам
Кабинет → «Изображения персонажей» какие состояния готовы
Игра → Hub                          экран «Сердце ЛЕММЫ» с семью зонами
Публичный лендинг                   очистить lemma-entered и прогресс,
                                    перезагрузить — откроется s-home.
                                    Сцену и карточки персонажей
                                    заполняет renderLanding()
Дом → «Для родителей»               экран s-parents с успеваемостью

ВЫКЛАДКА
Загрузить папку целиком, например через netlify.com/drop.
Адрес должен начинаться с https, иначе не работает микрофон.
