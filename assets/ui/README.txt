ЭЛЕМЕНТЫ ИНТЕРФЕЙСА
===================

Фирменные декоративные элементы: паттерны, разделители, фоны разделов,
рамки, иконки достижений.

Формат: SVG (предпочтительно) или WebP.

ОЖИДАЕМЫЕ ИМЕНА
  pattern_<название>.svg
  divider_<название>.svg
  frame_<название>.svg
  bg_<раздел>.webp
  badge_<id достижения>.webp

Идентификаторы достижений:
  brave  words  listen  grammar  steady  const  atlas

ПОДКЛЮЧЕНИЕ
ASSET_MANIFEST.ui в index.html.
