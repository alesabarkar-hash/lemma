# LEMMA v1.57.0 — handoff

Дата: 14 августа 2026.

Релиз собран поверх фактической production-базы `47c779e` (LEMMA v1.56.0),
полученной командой fetch непосредственно перед интеграцией. В него вошли
только принятые изменения Phase 2A, Correction Pass и Phase 2A.2.

## Состав релиза

- заметный вход «Учебник и материалы» на Topic Screen;
- современное оформление Hello L1/L2, feedback и Result;
- контекстные иллюстрации главы Hello и Family-сцена вместо заглушки;
- desktop-оболочка UX v2 для учебника;
- читаемый заголовок Result на mobile;
- централизованное отключение legacy educational ART;
- нейтральные дидактические компоненты там, где современная сцена отсутствует;
- исправление переполнения mobile Главной декоративным hero-свечением.

## Защищённые области

LESSONS, theory/tasks, правильные ответы, scoring, PROG, SAVED/resume,
locks, rewards/anti-farm, `nextTopicId`, controller-функции, порядок тем,
Review 1/2, содержание учебников, Мир и правила доступа не менялись.

Незакоммиченные `assets/topics/path/*-v1.webp` намеренно не входят в релиз:
они не удалялись и не изменялись. Новый ART PASS, включая abc1, не начинался.

## Проверка

Полный отчёт: `RELEASE_SMOKE_REPORT_v1.57.0.md`. Машиночитаемый протокол и
контрольные скриншоты находятся вне репозитория в каталоге release artifacts.
Новых известных ограничений по результатам проверки не осталось, поэтому
`KNOWN_ISSUES` не изменялся.
