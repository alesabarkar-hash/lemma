КАК ПОДКЛЮЧИТЬ НОВЫЕ ИЗОБРАЖЕНИЯ
1. Положите файлы в нужную папку с именами из её README.txt
2. Откройте index.html, найдите «КОНФИГУРАЦИЯ ПЕРСОНАЖЕЙ»
3. Впишите имена файлов без расширения в CHARACTER_READY
   Например: const CHARACTER_READY=["lumi_happy","echo_support"];
4. Проверить подключённое можно в Кабинете, раздел «Изображения персонажей»

Пока файла нет, показывается базовое изображение персонажа.
Битых ссылок не возникает.

ВЫКЛАДКА
Загрузите папку целиком на хостинг, например через netlify.com/drop.
Адрес должен начинаться с https, иначе не работает микрофон.
